Why Coding Awareness in Schools?

Aligned with National Education Policy (NEP 2020) for early computational literacy.

🧠

Logical & Critical Thinking

Coding trains children to break down complex problems into structured, manageable steps.

💻

Practical Digital Exposure

Moving students from just consuming digital games to creating interactive stories and apps.

📊

Survey-Driven Research

Backed by real empirical survey data collected from 74 students and teachers across schools.

Core Program Objectives

01

Demystify Programming

Remove the fear of coding by starting with visual block puzzles and interactive games.

02

Hands-on Foundation

Introduce Python syntax, web structure (HTML/CSS), and algorithmic flowcharts.

03

Assess Ground Challenges

Identify infrastructure gaps (computer availability, teacher training) through surveys.

04

Career Guidance

Guide young students regarding diverse career opportunities in technology and STEM fields.

Workshop Curriculum Modules

Designed step-by-step for beginner school students.

Module 1

Block Coding & Logic

Visual programming concepts using Scratch blocks for animations and puzzle solving.

  • Loops & Conditions
  • Coordinate system
  • Maze game project
Module 2 • Star Module

Python Fundamentals

Basic text-based coding with simple English-like syntax and logic building.

  • Variables & Data Types
  • If-Else Decisions
  • Interactive Quiz Game
Module 3

Web Basics

Understanding how websites work and building their first basic web page.

  • HTML Structure
  • CSS Styling & Colors
  • My First Profile Page
Module 4

Cyber Safety & AI

Safe internet habits, understanding modern AI tools, and IT career awareness.

  • Password Security
  • Responsible Tech Use
  • Future STEM Pathways
